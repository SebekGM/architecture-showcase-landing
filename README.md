# Modern Architecture Showcase

A professional, responsive landing page for an architectural firm. 
The project was created to demonstrate advanced CSS/SASS skills and clean HTML structure.

## 🛠 Technologies used:
- **HTML5** (Semantic tags)
- **SASS** (Variables, Mixins, Nesting)
- **BEM Methodology** (Naming convention)
- **Mobile First Approach** (Responsive Web Design)

## 🎯 Key Features:
- Fully responsive layout (Mobile, Tablet, Desktop)
- Clean and scalable CSS architecture
- Pixel-perfect implementation from Figma design
- Optimized assets for fast loading
